# Security

This repository contains public discovery metadata and documentation for the AutoID MCP service.

Do not commit or post:

- API keys or tokens
- private signing keys
- WordPress credentials
- SSH credentials
- customer or order data
- internal secrets

The public MCP endpoint is intended to remain read-only.

For security issues related to AutoID infrastructure, use AutoID's normal private support/contact channel rather than a public GitHub issue containing sensitive details.
